
# E-Commerce Product Gallery

A responsive e-commerce product gallery built with HTML and CSS Grid.

## Features

- CSS Grid with `auto-fit` and `minmax(250px, 1fr)` for automatic responsiveness
- No media queries required
- Hover animations on product cards and images
- Clean, modern UI with header, gallery, and footer

## Technologies Used

- HTML5
- CSS3 (Grid Layout, Transitions)
